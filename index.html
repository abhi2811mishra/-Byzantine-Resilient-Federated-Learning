Theorem 2: Breaking Krum via IPM Ready

Identical colluding Byzantine updates have zero mutual distance. They create an artificial dense cluster, tricking Krum into selecting a malicious update.

Step-by-Step Terminal Execution Guide

Copy and run any command in PowerShell from d:\byzantine_fl:

1. Math & Theorem Verification
.\venv\Scripts\python.exe test_math.py

Validates Theorems 1 & 2 without neural network training. Confirms median sign flip and Krum cluster entrapment.

2. Run Centralized & FedAvg Baselines
.\venv\Scripts\python.exe week2_mnist_baseline.py ; .\venv\Scripts\python.exe week4_noniid.py

Establishes the centralized benchmark (98.7%) and compares IID FedAvg (97%) against non-IID FedAvg (77%).

3. Interactive Live Viva Demonstration
.\venv\Scripts\python.exe demo.py

Launches the interactive CLI demo: select clients, attack, aggregator, and view live comparative tables and graphs.

4. Compile Metrics & Plots
.\venv\Scripts\python.exe metrics_analysis.py ; .\venv\Scripts\python.exe plot_results.py

Exports `results/robustness.csv`, `results/recovery.csv`, and all 20 publication figures into `plots/`.
